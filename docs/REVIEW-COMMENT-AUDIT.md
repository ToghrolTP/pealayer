## Remaining acceptance gates

1. **Network authentication:** browser-origin restrictions and an explicit `PEALAYER_WEB_ALLOWED_ORIGINS` allowlist are implemented, but unauthenticated native LAN clients remain allowed. A shared access-token policy must be decided and wired through native peers, CLI, REST, WebSocket and Web UI. Do not expose this server to an untrusted network; use an authenticated TLS proxy meanwhile. This finding stays open.
2. **Persistence completion:** RPC responses now reach callers, but effect saves need a correlated final PCController completion/error receipt before the editor can truthfully treat a queued request as a durable save. The response-correlation finding stays open until that contract is completed.
3. **Verification boundary:** `cargo check --tests --locked` and Web TypeScript checks passed. The production Vite/PWA generation passed. New regression checks were added and compiled, **not executed**, respecting the request to avoid test suites. No claim of live GUI, physical hardware, packaged DLL smoke-test, or cleared CodeQL alerts is made. No running player was replaced in this pass.

## Preservation and behavior changes

No hardware capabilities, actual output assignments, effect steps, recording engine, peer routing or useful UI features were intentionally removed. The removed generated `message.js` chunk is a Vite bundling change, not deletion of notification behavior: the imported Ant Design message implementation is bundled elsewhere. Retired project target labels are accepted only by the one-way file migration; no old public enum names or hardcoded actuator assignments were restored. Browser-to-peer connections from a different origin must be explicitly allowlisted; normal same-origin UI and native peer routing remain supported.

# Pealayer

Pealayer is a desktop media player and timeline authoring surface for synchronized
cinema hardware. Media playback is local; PCController remains the authoritative
owner of connected boards, capabilities, relay names, effects, macros, and live
hardware state.

## Start here

- [Install and package Pealayer](Installation-and-Packaging)
- [Play media and author experiences](Playback-and-Authoring)
- [Connect PCController and operate hardware safely](Hardware-and-Safety)
- [Configure branding, themes, and Persian RTL](Configuration-Branding-and-Localization)
- [Troubleshoot a deployment](Troubleshooting)

Pealayer never fills a missing device, capability, effect, relay, or telemetry
value with a sample. Unavailable features stay hidden or identify the actual
loading, disconnected, degraded, or failed state.

# Remote locations and folders

Pealayer discovers HTTP(S) directory indexes and a media file's siblings through one Rust service. Native, HTTP/JSON, JSON-RPC, CLI/native IPC, and WebSocket clients share the same listing, selection, sort order and proxy policy. The native dialog and Web dialog render that service rather than scraping independently.

## Start here

- Native: **File → Browse remote folder…**, or **Open Location / URL → Browse folder**. Paste a file or folder URL, choose whether to use a proxy, and select **Browse**.
- Web: select the folder icon in the header. The listing is shared live with the native app. Select a row for details; double-click a file to play or a folder to enter it. Right-click for Play/Open folder, file information and Copy URL.
- Ordinary media opens retain immediate playback, with sibling discovery running in the background. A directory supplied to the ordinary Open command opens the folder browser instead of trying to play HTML.
- Choose Name, Date or Size sorting, filter by filename, and use **Parent folder** to navigate up. Names are URL-decoded once, with natural numeric and season/episode ordering. Directories remain before files. Dates retain the server's text; no timezone is invented. Missing size/date values are shown as unavailable.
- **Automatically play next file** is unchecked by default. Enable it here or in **Preferences → Playback → Remote folders**. It advances once at EOF, stops at the final item, and does not wrap. Explicit Next/Previous commands work regardless of this preference. Native transport context menus expose contextual Previous/Next file actions.
- Thumbnails are enabled by default, cached in OS-native thumbnail storage and generated by the existing silent FFmpeg/MPV pipeline at approximately 20% of finite media, or an initial decodable frame for streams. Generation is asynchronous and limited to two folder workers. Unsupported/undecodable thumbnails do not prevent file selection or playback.

## Commands

```powershell
pealayer --browse "https://files.example/folder/" --no-proxy
pealayer "https://files.example/folder/clip.mp4"
pealayer --remote '{"command":"browse_remote","target":"https://files.example/folder/","use_proxy":false}'
pealayer --next
pealayer --previous
```

Send these JSON commands to native IPC, `POST /api/ipc`, `POST /api/player/command`, or `/ws`:

```json
{"command":"browse_remote","target":"https://files.example/folder/","use_proxy":false}
{"command":"select_remote","target":"https://files.example/folder/clip.mp4","play":true}
{"command":"sort_remote","by":"name","descending":false}
{"command":"close_remote_browser"}
```

Equivalent JSON-RPC methods are `pealayer.remote.browse`, `.select`, `.sort`, `.close`, and the existing `pealayer.player.open`, `next` and `previous` commands. Example:

```json
{"jsonrpc":"2.0","id":1,"method":"pealayer.remote.browse","params":{"target":"https://files.example/folder/","use_proxy":false}}
```

`GET /api/remote/state` returns the authoritative browser state. `/api/player/status` and `/ws` snapshots include it as `remote_browser`. `GET /api/remote/thumbnail?url=<encoded-listed-url>` returns HTTP 202 while pending, a JPEG when ready, or a specific error. Thumbnail targets must belong to the current listing. Web file-access and control permissions are enforced for remote browsing/selection commands, including commands nested in launch requests.

## Proxy, host information and limits

**Use proxy** off explicitly bypasses environment and custom proxies for directory/file inspection, thumbnail decoding and playback. With proxy use on, a configured custom proxy is used; otherwise the normal environment proxy policy applies. Requests identify the app using `Pealayer/<version> (+https://github.com/ToghrolTP/pealayer)`.

The browser handles HTML tables, Apache/nginx-style preformatted indexes, and query-parameter directory pages with list metadata. It follows normal HTTP redirects, resolves relative links, deduplicates canonical URLs and excludes unrelated origins and ancestor links from the current listing. Query-based parent navigation preserves unrelated query parameters. Pages are capped at 4 MiB and 5,000 entries. Large Web listings paginate; native rows are virtualized.

JavaScript-only catalogs, embedded URL credentials, authentication workflows and non-HTTP directory protocols are not supported. A file can still play when its host does not allow sibling discovery; the browser reports that limitation. No user-provided test host or media name belongs in repository fixtures or screenshots.
